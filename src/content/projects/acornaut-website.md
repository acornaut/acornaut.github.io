I changed my username from TheCrispyAcorn to Acornaut because I wanted something new while still keeping the nick/display name 'Acorn', since everyone in the online space know me as such. This site is where I plan to keep any cool/development info about my Hytale mods, random software projects, writing, and whatever other little experiments I end up making.

I might forget this website exists like most of my projects, but it was fun to make nonetheless. When I remember it, I'll probably come back and add another project or writing piece. Or not, who knows!

Libraries used: React, Vite, Three.js, and Canvas UI's Ascii Object component.

The ASCII acorn effect uses Canvas UI's Ascii Object component with acorn art made by my friend Banshee.
